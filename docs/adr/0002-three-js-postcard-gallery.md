# Use three.js for the category postcard galleries

The category pages (`/charts`, `/maps`, `/creative-code`) show their projects as postcards scattered once on a bounded, draggable plane with fly-to-centre enlargement and a flip to a drawn back face — dozens of freely transformed, tilted quads plus a future for shader-driven backgrounds, which is where ADR-0001's DOM approach stops paying off. These pages render the plane with three.js directly (no threlte) on a transparent canvas over a CSS background layer, so the background stays swappable (a tint today, maybe a three effect or a real map later). Interaction and text stay in the DOM on top of the canvas: brand link, section switcher, the open card's row of real links, and a visually hidden list of links to every project page keep the gallery reachable, crawlable and prerendered; opening or flipping a card never changes the URL. three is loaded only on gallery routes via a dynamic import inside an attachment, so the landing page ships no WebGL. ADR-0001 still governs the landing wall.
